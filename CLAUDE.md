# CLAUDE.md

Guidance for Claude/Copilot when working in this repository.

## Overview

This is a personal multi-host NixOS configuration built with Nix flakes and
Home Manager. A single `flake.nix` defines several `nixosConfigurations`,
each corresponding to a physical machine ("host"). Hosts share common logic
via reusable modules and only override what's host-specific.

## Repository Structure

```
flake.nix              # Entry point; declares inputs and the 4 nixosConfigurations
hosts/                 # One directory per machine
  framework/
  framework_desktop/    # <- this host, see below
  ryzen_rtx/
  t7910/
    configuration.nix          # system-level config, imports shared modules
    hardware-configuration.nix # generated by nixos-generate-config; DO NOT hand-edit
    home.nix                   # Home Manager config for the primary user
modules/
  nixos/                # System-level (NixOS) modules, imported from hosts/*/configuration.nix
    common-packages.nix   # Package set installed on every host
    hardware.nix, nvidia.nix, docker.nix, nginx.nix, tomcat.nix,
    ollama.nix, sunshine.nix, avahi.nix, display-manager.nix,
    environment.nix, fonts.nix, python.nix, steam.nix, virtual.nix,
    wayland.nix, httpd.nix
    package-config/       # git.nix, openssh.nix
  home-manager/          # Home Manager modules (user-level), e.g. hyprland.nix,
                          # nixvim(.nix), stylix.nix, zsh.nix, tmux.nix, ghostty.nix,
                          # kitty.nix, eww.nix, tofi.nix
```

## Flake Inputs

- `nixpkgs` — `nixos-unstable`
- `home-manager` — follows nixpkgs
- `hyprland` — built from source (git submodules), used for the WM
- `stylix` — theming
- `nixvim` — Neovim configured in Nix
- `nix-environments`, `epic-bar-rs` (author's own status bar)

All 4 hosts import `inputs.home-manager.nixosModules.default` and
`inputs.nixvim.nixosModules.nixvim`; GPU-specific hosts additionally pull in
`modules/nixos/nvidia.nix` (t7910, ryzen_rtx) or rely on AMD graphics
(framework, framework_desktop).

## Conventions

- **Adding a package everywhere**: add to `modules/nixos/common-packages.nix`.
  Host-specific packages go in that host's `configuration.nix` under
  `environment.systemPackages` (NixOS merges the lists).
- **Adding a system-level feature/service**: create/extend a module under
  `modules/nixos/` and import it from the relevant host's `configuration.nix`.
- **Adding a user-level (dotfiles/CLI) feature**: create/extend a module under
  `modules/home-manager/` and import it from the host's `home.nix`.
- **Never hand-edit `hardware-configuration.nix`** — it's machine-generated.
- Primary/only user across hosts is `dylandy`.
- Shell is `zsh` with `antidote` plugin manager, `starship` prompt, vi-mode
  keybindings (`zsh-vi-mode`), and `fzf`/`fzf-tab` integration; configured in
  home.nix per host (currently duplicated, not yet its own module for this
  host — check `modules/home-manager/zsh.nix` before duplicating further).
- Rebuild/switch alias: `nix-reflake <hostname>` → `sudo nixos-rebuild switch --flake .#<hostname>`.
- `system.stateVersion` / `home.stateVersion` = `24.05` — do not bump without
  a deliberate decision (this is NOT the NixOS release version to track).

## framework_desktop Host Specifics

Path: `hosts/framework_desktop/`

**Hardware**: Framework Desktop, AMD Ryzen AI Max ("Strix Halo", AI 395),
integrated `gfx1151` GPU (RDNA3.5), no discrete GPU — only a small 512MiB
VRAM carveout with the rest of the unified memory shared via GTT.
`hostName = "framework-amd-ai395"`. AMD microcode enabled via
`hardware-configuration.nix`. Kernel: `linuxPackages_6_18`. Boot: systemd-boot,
EFI. `boot.binfmt.emulatedSystems = [ "aarch64-linux" ]` for cross-arch builds.

**GPU/compute**:
- `hardware.graphics` (32-bit enabled) + `rocmPackages.clr.icd` for OpenCL.
- `hardware.amdgpu.initrd.enable` and `opencl.enable`.
- Custom ROCm environment symlinked to `/opt/rocm` via
  `systemd.tmpfiles.rules` (joins `rocblas`, `hipblas`, `clr`).
- `boot.kernelParams = [ "amdgpu.gttsize=102400" ]` — raises the GTT
  (unified memory pool) to 100GiB (from a ~62.5GiB default) so large local
  LLMs (e.g. `gpt-oss:120b`, ~66GiB) fit; leaves ~25GiB for the host. See the
  comment in `configuration.nix` if this ever needs revisiting on a different
  RAM size.
- `modules/nixos/ollama.nix`: runs `ollama-rocm` targeting `gfx1151`
  (`rocmOverrideGfx = "11.5.1"`), single-GPU env vars
  (`ROCR_VISIBLE_DEVICES`/`HIP_VISIBLE_DEVICES=0`), `OLLAMA_LOAD_TIMEOUT=30m`
  for large model loads, preloads a list of models (qwen3 variants,
  llama3.1, deepseek-r1, qwen2.5:72b, gpt-oss:120b).

**Networking** (this host has the most elaborate networking of any host —
it's used on a corporate network):
- NetworkManager with `dns = "systemd-resolved"` for split DNS: corporate
  domains route to corporate DNS servers (`10.94.2.200`, `10.86.2.200`),
  everything else uses the active connection's DNS (e.g. a USB dock's
  8.8.8.8/1.1.1.1). `services.resolved.settings.Resolve.FallbackDNS` mirrors
  the corporate DNS as a fallback; DNSSEC disabled (corporate network breaks
  it).
- Long list of static routes on `enp191s0` (corporate subnets via a
  `158.100.89.254` gateway) and a default route on `enp196s0f0u2u1` (a
  USB-connected dock/adapter). **If NIC names change (different dock/cable),
  these `interfaces.<name>.ipv4.routes` blocks will silently stop applying**
  — check `ip link` after hardware changes.
- NFS mount at `/mnt/shared` (`10.10.101.31:/srv/nfs/shared`, automount).

**Services/software unique to this host** (imported in `configuration.nix`):
`display-manager.nix`, `package-config/openssh.nix`, `common-packages.nix`,
`fonts.nix`, `environment.nix`, `python.nix`, `docker.nix`, `nginx.nix`
(fileserver on ports 80/8080, root `/var/www/html`), `sunshine.nix`
(game-streaming host, opens ports 47984-48010; note: contains a **plaintext
password in `environment.etc."sunshine/sunshine.conf"`** — treat as sensitive
and consider moving to a secret if this repo is ever made public/shared),
`avahi.nix` (mDNS), `ollama.nix`, `tomcat.nix` (serves an OpenGrok WAR on
port 9090).

**Desktop**: Hyprland (Wayland) built from the `hyprland` flake input,
`xwayland.enable = true`; pipewire audio stack; `xdg.portal.enable`;
`WLR_NO_HARDWARE_CURSORS=1` and `NIXOS_OZONE_WL=1` session vars.

**Misc**: `nix-ld` enabled (run unpatched dynamic binaries), `nofile` ulimit
raised to 65536, Bluetooth enabled with `powerOnBoot`, one insecure package
permitted (`gradle-7.6.6`).

## Working in This Repo

- Prefer editing a shared `modules/` file over duplicating logic across
  `hosts/*/configuration.nix` when a change should apply to multiple hosts.
- Before adding a new module option, check whether an existing module
  (`modules/nixos/*` or `modules/home-manager/*`) already covers it.
- Validate changes with `nix flake check` or a targeted
  `sudo nixos-rebuild build --flake .#<hostname>` (build, not switch, to avoid
  activating on a machine you don't intend to affect) when possible — but
  note actual rebuilds require running on the physical target host.
- Do not commit secrets (see the sunshine.conf caveat above); prefer
  `sops-nix`/agenix-style secret management if adding new credentials.
